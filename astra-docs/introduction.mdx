## What is Astra?

Astra is a **code-first DSL compiler for multi-agent orchestration**. Instead of running a language model inside a ReAct loop at every step, Astra uses the model **once** to produce a short Python program, validates it against compile-time safety rules, compiles it into a typed execution graph, and runs that graph deterministically with **no further model calls during execution**.

The result: **bounded LLM calls (~3 per query)** regardless of how many tools or agents the workflow uses, plus an inspectable execution plan and a fully replayable audit trail.

## How it works

The LLM is called exactly **three times** per query — every query, regardless of how many tools or agents the workflow uses.

The dashed step in the middle is where Astra differs from ReAct: a typed execution graph runs deterministically with **zero LLM calls**. The third LLM call only fires at the end to format the answer.

For the full pipeline (DSL → AST → typed graph → executor), see [Architecture](/concepts/architecture).

## Headline numbers

On a 4-analyst investment-research workload (90 trials, 5 frameworks):

| Architecture | n | LLM calls | tokens (mean / p95) | wall p50 (s) |
| --- | --: | --: | --: | --: |
| **Astra (compiled)** | 18 | **3.0** | **21,013 / 28,804** | **26.1** |
| ReAct pool (Agno + CrewAI + AutoGen) | 54 | 16.1 | 49,219 / 85,452 | 50.3 |
| Hand-graph (LangGraph) | 18 | 10.4 | 29,645 / 55,086 | 32.4 |

Against the pooled ReAct baseline: **5.37× fewer LLM calls, 2.34× fewer tokens, 1.93× faster wall p50**. Full numbers, ratios, and reproduction in [`benchmarking/`](https://github.com/astra-dev/astra/tree/main/benchmarking) and the [research paper](https://github.com/astra-dev/astra/blob/main/paper/main.pdf).

## When to choose Astra

<CardGroup cols={2}>
  <Card title="Choose Astra when" icon="circle-check">
    - Your workflow is **sequential and structured** (most multi-agent pipelines are)
    - You need **predictable cost** per query
    - You want a **typed, inspectable plan** before tools run
    - Compile-time safety matters (AST validation, no shell/file/network escape)
  </Card>
  <Card title="Choose a ReAct loop when" icon="circle-info">
    - The workflow must **replan mid-execution** based on intermediate results
    - You need **adaptive recovery** from unexpected tool outputs
    - The problem is **exploratory** rather than structured
  </Card>
</CardGroup>
