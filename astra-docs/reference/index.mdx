## How these pages are generated

The reference is rebuilt nightly (and on every push to `main` that touches
the source or the build scripts) by
[`scripts/build-reference.py`](https://github.com/astra-dev/astra/blob/main/astra-docs/scripts/build-reference.py).
It uses [griffe](https://mkdocstrings.github.io/griffe/) in static mode to
parse the source, then renders Jinja2 templates that emit Mintlify-flavoured
MDX. The resulting changes land via an automated `docs/reference-refresh`
pull request.
