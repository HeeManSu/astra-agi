`astra-observability` captures every span, message, and tool call that
flows through a running [`astra-framework`](/reference/framework) app. It
exposes a tracing engine, OpenTelemetry-compatible instrumentation, a
pluggable storage layer, a query API, a live-streaming subscriber, and
debug helpers used by the Playground UI.

Install it with:

```bash
pip install astra-observability
```
