`astra-runtime` hosts a compiled [`astra-framework`](/reference/framework)
app behind an HTTP and WebSocket surface. It exposes an app factory, a route
registry, pluggable auth, and the primitives used by the agent registry and
worker-pool synchroniser.

Install it with:

```bash
pip install astra-runtime
```
