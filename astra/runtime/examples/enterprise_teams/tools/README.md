# Enterprise Teams Tools

This example includes:
- 60 local domain tools (12 per domain module)
- 5 shared MCP toolkits (`brave_search`, `duckduckgo`, `github`, `notion`, `fetch`)
- 17 tools available per team bundle (12 local + 5 MCP)

All MCP instances are created once in `tools/__init__.py` and reused by all agents.
